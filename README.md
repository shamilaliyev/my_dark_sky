# My Dark Sky

A Flask weather app inspired by Dark Sky.

## Features

- Search weather by city
- Use current browser location
- View today's weather
- Choose a future date for forecast
- Choose a past date for weather history
- Store weather results in a JSON cache for 5 minutes

## How to run

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the app:

```bash
python app.py
```

Open the app in the browser:

```bash
http://127.0.0.1:5000
```
